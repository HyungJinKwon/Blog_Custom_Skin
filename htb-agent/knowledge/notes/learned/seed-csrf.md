# 학습 시드: csrf (큐레이션 요약)

> 사전 심은 큐레이션 개념 요약(확립된 보안 지식). 라이브 수집 아님 — 권위 출처에서 검증 가능. 최신 본문은 `assassin --learn csrf` 로 갱신.

사이트간 요청 위조: 피해자 인증세션으로 의도치 않은 상태변경 요청 강제. 쿠키 자동전송 + 예측가능 요청 + 상태변경 액션일 때 성립. 완화: CSRF 토큰(동기화/이중제출)·SameSite 쿠키·커스텀 헤더 검증. 블루팀: 교차출처 Referer/Origin 의 상태변경 요청 이상.

- 출처(검증): https://portswigger.net/web-security/csrf
