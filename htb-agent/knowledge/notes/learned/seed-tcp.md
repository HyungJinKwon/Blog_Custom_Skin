# 학습 시드: tcp (큐레이션 요약)

> 사전 심은 큐레이션 개념 요약(확립된 보안 지식). 라이브 수집 아님 — 권위 출처에서 검증 가능. 최신 본문은 `assassin --learn tcp` 로 갱신.

RFC 9293. TCP 전송계층: 3방향 핸드셰이크(SYN/SYN-ACK/ACK)·상태머신·순서/재전송. 스캔 원리의 기반(SYN/connect/FIN/NULL/XMAS). 블루팀: 비정상 플래그조합·하프오픈 스캔 탐지. 참고: 포트스캔 동작·방화벽 응답 해석의 기초.

- 출처(검증): https://datatracker.ietf.org/doc/html/rfc9293
