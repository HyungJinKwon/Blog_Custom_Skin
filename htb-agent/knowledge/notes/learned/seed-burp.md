# 학습 시드: burp (큐레이션 요약)

> 사전 심은 큐레이션 개념 요약(확립된 보안 지식). 라이브 수집 아님 — 권위 출처에서 검증 가능. 최신 본문은 `assassin --learn burp` 로 갱신.

웹 프록시 기반 평가 도구. Proxy로 요청가로채기/변조, Repeater 반복테스트, Intruder 퍼징, Decoder/Comparer. Web Security Academy로 기법 학습. 공식 portswigger.net.

- 출처(검증): https://portswigger.net/burp/documentation
