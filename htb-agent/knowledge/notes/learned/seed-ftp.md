# 학습 시드: ftp (큐레이션 요약)

> 사전 심은 큐레이션 개념 요약(확립된 보안 지식). 라이브 수집 아님 — 권위 출처에서 검증 가능. 최신 본문은 `assassin --learn ftp` 로 갱신.

RFC 959. FTP 평문 프로토콜(21 제어/20 데이터), 익명로그인(anonymous) 흔함. 능동/수동 모드. 보안: 평문 자격 스니핑·바운스 공격. 열거: 익명 접근·쓰기가능 디렉터리·설정파일 노출 점검. 블루팀: 평문 자격 노출·비정상 전송. 완화: FTPS/SFTP 대체·익명 비활성.

- 출처(검증): https://datatracker.ietf.org/doc/html/rfc959
