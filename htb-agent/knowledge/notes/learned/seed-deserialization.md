# 학습 시드: deserialization (큐레이션 요약)

> 사전 심은 큐레이션 개념 요약(확립된 보안 지식). 라이브 수집 아님 — 권위 출처에서 검증 가능. 최신 본문은 `assassin --learn deserialization` 로 갱신.

신뢰 불가 직렬화 데이터 역직렬화→객체 주입·RCE(Java ysoserial, PHP POP체인, .NET). 완화: 역직렬화 금지/서명, 안전 포맷(JSON+스키마), 타입 화이트리스트.

- 출처(검증): https://cheatsheetseries.owasp.org/cheatsheets/Deserialization_Cheat_Sheet.html
