# 학습 시드: http (큐레이션 요약)

> 사전 심은 큐레이션 개념 요약(확립된 보안 지식). 라이브 수집 아님 — 권위 출처에서 검증 가능. 최신 본문은 `assassin --learn http` 로 갱신.

요청라인+헤더+바디. 메서드(GET/POST/PUT...), 상태코드(2xx/3xx/4xx/5xx). 보안헤더 CSP/HSTS/X-Frame-Options. 쿠키 플래그 HttpOnly/Secure/SameSite. 참조 RFC 9110.

- 출처(검증): https://developer.mozilla.org/en-US/docs/Web/HTTP
