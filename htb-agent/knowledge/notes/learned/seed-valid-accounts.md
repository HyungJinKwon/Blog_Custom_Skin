# 학습 시드: valid-accounts (큐레이션 요약)

> 사전 심은 큐레이션 개념 요약(확립된 보안 지식). 라이브 수집 아님 — 권위 출처에서 검증 가능. 최신 본문은 `assassin --learn valid-accounts` 로 갱신.

ATT&CK T1078. 유효계정 악용: 탈취·기본·휴면 자격으로 정상사용자처럼 접근(초기접근·지속성·권한상승·회피 동시충족). 기본자격·재사용 암호 흔함. 블루팀: 비정상 시간/위치 로그인, 휴면계정 활성화, 불가능 이동(impossible travel) 탐지. 완화: MFA·기본자격 제거·조건부접근.

- 출처(검증): https://attack.mitre.org/techniques/T1078/
