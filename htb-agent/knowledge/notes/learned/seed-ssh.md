# 학습 시드: ssh (큐레이션 요약)

> 사전 심은 큐레이션 개념 요약(확립된 보안 지식). 라이브 수집 아님 — 권위 출처에서 검증 가능. 최신 본문은 `assassin --learn ssh` 로 갱신.

RFC 4253. SSH(22) 보안 원격접속. 공격면: 약한 자격 브루트포스, 키 오관리, 노출 개인키, 에이전트 포워딩 남용, 포트포워딩 피벗. 블루팀: 반복 인증실패·비정상 키 로그인·터널링 탐지. 완화: 키인증·암호로그인 비활성·fail2ban·MFA.

- 출처(검증): https://datatracker.ietf.org/doc/html/rfc4253
