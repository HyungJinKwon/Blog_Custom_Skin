# 지식베이스 (사용자 학습데이터)

여기에 당신의 노하우를 넣으면 에이전트가 '성장'합니다. 외부 라이트업은
참조하지 않습니다 — **당신이 넣은 자료, 권위 출처 학습, 교차검증된 웹 학습(HTB 라이트업 차단)만** 사용합니다.

## 규칙 추가 (rules/*.json)
관측(OS·포트·서비스)에 맞는 다음 액션을 제안하도록 규칙을 추가하세요.
스키마는 `src/htb_agent/knowledge.py` 상단 주석 참고. 예시는 `rules/example.json`.

- `{t}` 만 쓰는 명령은 자동실행 후보(승인 게이트 통과 시).
- `{user}`,`{pass}`,`{domain}` 등은 '수동 제안'으로 분류되어 자동실행되지 않습니다.

## 노트 추가 (notes/*.md, *.txt)
자유 서술 노하우. 맥락으로 제공됩니다(노트당 최대 6000자, 관련도 상위 노트만 주입).
이 README 자체는 노트로 읽히지 않습니다.

## 자동으로 쌓이는 노트
`notes/` 아래는 하위 폴더까지 모두 로드됩니다.

| 위치 | 만드는 방법 | 공유 |
|---|---|---|
| `learned/seed-*.md` | 번들 시드(카탈로그 59주제 + 보조 3) — 누구나 같은 지식으로 시작 | 저장소 추적 |
| `learned/learned-*.md` · `learned-web-*.md` | `--learn` · `--learn-gaps` · `--web-learn` 이 권위·교차검증 출처에서 생성 | 로컬 전용(.gitignore) |
| `ingested/` | `--ingest <경로>` 로 넣은 본인 자료 | 로컬 전용(.gitignore) |

- `--promote <주제|all>`: 로컬 학습 중 품질 관문을 통과한 항목만 시드의 `## 최신 보강(승격)` 섹션으로
  옮깁니다(주제당 3건). 커밋·PR 로 모든 사용자의 시작 지식이 함께 자랍니다(매주 자동 승격 워크플로도 동일).
- 실행 시 하루 1회 공유 저장소의 최신 시드를 검증 후 `knowledge/shared_seeds/` 캐시에 반영합니다
  (`--no-kb-sync` · `--offline` 으로 끔). 추적 파일은 바꾸지 않습니다.
